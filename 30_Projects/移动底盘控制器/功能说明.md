# 移动底盘控制器功能说明

## 项目背景

该项目是一个集成工控机、STM32 实时控制、HMI、网络通信和多传感器接口的控制平台。

## 功能模块

- 电源管理：输入电源、DC-DC 转换、电源监控、保险丝、急停，必须。
- 主控计算模块：Linux 运行、ROS2、导航、HMI、网络通信，必须。
- 实时运动控制模块：电机控制、编码器采集、里程计计算，必须。
- 通讯管理模块：CAN、RS485、Ethernet、USB，必须。
- 传感器接口模块：激光雷达、IMU、超声波、GPS 等，必须。
- 安全控制模块：急停、安全继电器、防撞、安全 IO，必须。
- 网络模块：WiFi、千兆网口、4G/5G，建议。
- 人机交互 HMI：触摸屏、状态显示、参数设置，建议。
- 数据记录：日志、地图、故障记录，建议。
- 远程维护：SSH、Web 管理、OTA 升级，建议。

## 系统分工

- Linux 工控机：主控计算、传感器管理（雷达/相机）、网络通信、HMI、系统配置、数据管理、软件升级。
- STM32：实时运动控制、电机驱动管理、传感器采集（IMU/编码器/IO）、现场总线通信、安全保护、设备诊断。
- 其他硬件：电源模块/BMS、电机驱动器、触摸屏、急停按钮、安全继电器。

## 核心模块说明

- 电源管理：DC48V 输入，多路 DC 输出（48V/24V/12V/5V/3.3V），电压电流检测、电池状态检测、电源保护、急停断电。
- 主控计算：Ubuntu、ROS2、SLAM、Navigation2、路径规划、多传感器融合、HMI、数据记录、网络通信、参数管理。
- 实时运动控制：电机速度/位置闭环、PID、编码器采集、底盘运动学、里程计、PWM 输出、IO 控制、实时状态反馈。
- 电机驱动管理：驱动器通信、电机启停、速度控制、状态反馈、电流监测、故障报警。
- 传感器管理：Linux 负责激光雷达、双目/RGB/深度相机、USB 设备；STM32 负责 IMU（CAN/UART）、编码器、超声波、GPIO 传感器、模拟量采集。
- 安全控制：急停、防撞、电机故障、驱动器/IMU/BMS 掉线检测、通信超时、故障联锁、安全停机。
