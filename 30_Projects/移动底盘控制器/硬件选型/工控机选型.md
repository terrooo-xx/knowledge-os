# 移动底盘控制器工控机选型

## 项目背景

工控机负责上层控制，承担计算量大、非硬实时的任务；STM32 负责实时控制。

## 工控机职责

- ROS2 运行环境：节点管理、Topic、Service、Action 通信。
- 设备驱动管理：激光雷达、相机、触摸屏、网络等。
- SLAM：建图、定位、地图保存与加载。
- 导航 Nav2：全局/局部路径规划、避障、路径跟踪。
- 运动指令生成：根据导航结果生成 /cmd_vel。
- 视觉处理：双目相机、AI 识别、AprilTag 等，可选。
- HMI：参数配置、状态监控、地图显示、手动控制。
- 网络通信：WiFi、Ethernet、4G/5G、远程升级。
- 数据记录：rosbag、日志、故障记录。
- 系统与升级管理：软件启动、节点管理、时间同步、软件更新。

## CPU 推荐

- Intel N97：小型机器人。
- Intel N100：性价比最高。
- Core i3-1215U：中型机器人。
- Core i5-1235U：高性能。
- Core i7：AI 视觉任务多时考虑。
