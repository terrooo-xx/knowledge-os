# STM32 DMA 测试资料

DMA（Direct Memory Access，直接存储器访问）用于在不占用 CPU 的情况下，在内存与外设之间搬运数据。

配置要点：

1. 使能 DMA 控制器和外设时钟。
2. 配置 DMA 通道：数据方向、外设地址、内存地址、传输数据量、数据宽度和优先级。
3. 配置传输模式，例如普通模式或循环模式。
4. 使能 DMA 中断，或使用轮询方式检查传输完成标志。
5. 启动外设请求，DMA 开始搬运数据。

常见应用：ADC 连续采样、SPI 收发、USART 收发、内存到内存复制。

注意事项：DMA 传输前确认地址对齐；循环模式注意缓冲区覆盖；高优先级通道可能抢占低优先级通道；中断处理中清除传输完成、半传输和传输错误标志。
