# project-doc-maintainer

功能：维护无人机飞控和移动底盘控制器项目文档。

## 工作流程

1. 阅读根目录 `AGENTS.md` 及其引用的系统级规范 `90_System/KNOWLEDGE_OS.md`（目录职责、AI 权限、审核边界）。
2. 确认用户指定的项目和检查范围。
3. 检查目录、索引和实际文件是否一致。
4. 检查功能模块是否符合固定模板。
5. 检查 Linux 工控机和 STM32 职责是否重复或冲突。
6. 检查接口名称、方向、协议和数据说明是否一致。
7. 检查项目文档是否重复解释 Wiki 已有知识。
8. 通用知识应改为内部链接。
9. 不得擅自补充未经确认的硬件参数。
10. 默认先生成检查报告。
11. 只有用户明确要求修改时，才修改正文。
12. 修改后更新文档的 `updated` 和变更记录。
13. 完成后列出所有修改和待确认事项。
