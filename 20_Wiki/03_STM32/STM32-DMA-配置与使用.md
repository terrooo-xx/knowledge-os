# STM32 DMA 配置与使用

## 一、概念/定义

DMA（Direct Memory Access，直接存储器访问）是一种用于在不占用 CPU 的情况下，在内存与外设之间搬运数据的技术。

## 二、工作原理

DMA 控制器在配置完成后，可以独立于 CPU 执行数据搬运任务，将数据在内存和外设之间直接传输，从而释放 CPU 资源用于其他处理。

## 三、核心机制

DMA 的配置要点包括：

1. 使能 DMA 控制器和外设时钟。
2. 配置 DMA 通道：数据方向、外设地址、内存地址、传输数据量、数据宽度和优先级。
3. 配置传输模式，例如普通模式或循环模式。
4. 使能 DMA 中断，或使用轮询方式检查传输完成标志。
5. 启动外设请求，DMA 开始搬运数据。

## 四、配置/实现

DMA 的配置流程遵循上述核心机制中的步骤，具体实现时需按顺序完成时钟使能、通道参数配置、传输模式选择、中断或轮询方式设定，以及外设请求启动。

## 五、关键参数

- 数据方向：定义数据传输的方向（如外设到内存、内存到外设等）。
- 外设地址：外设寄存器的地址。
- 内存地址：内存缓冲区的地址。
- 传输数据量：一次 DMA 传输的数据单元数量。
- 数据宽度：每次传输的数据位宽（如字节、半字、字）。
- 优先级：DMA 通道的优先级设置。
- 传输模式：普通模式或循环模式。

## 六、常见问题

- DMA 传输前需确认地址对齐。
- 循环模式下需注意缓冲区覆盖问题。
- 高优先级通道可能抢占低优先级通道。
- 中断处理中需清除传输完成、半传输和传输错误标志。

## 七、与相关知识的关系

DMA 常用于 ADC 连续采样、SPI 收发、USART 收发、内存到内存复制等场景，与 STM32 的外设配置（如 USART）密切相关。
