# CPU 与寄存器

## 核心概念

CPU 只知道访问某个地址、读写数据。寄存器是 CPU 内部最快速的小容量存储单元，用于暂时保存 CPU 或硬件模块当前需要使用的数据、状态和控制信息。内存 RAM 是 CPU 外部存放程序运行数据的空间。

## 主要寄存器

- PC（Program Counter）：保存下一条要执行的指令地址，CPU 下一步执行哪里看 PC。
- SP（Stack Pointer）：记录函数调用时的数据位置。

CPU 访问寄存器和内存的方式都是：访问地址 → 总线 → 对应硬件。

## 寄存器与外设寄存器的区别

- CPU 寄存器位于 CPU 内部，作用是为 CPU 计算服务，编译器自动使用，数量几十个，访问最快。
- 外设寄存器位于芯片外设模块内部，作用是控制硬件，程序员经常直接操作，数量几百到几千个，通过内存映射地址访问。

STM32 的 GPIO、USART、SPI、TIM、CAN、ADC 等外设都有自己的寄存器。

## STM32 地址空间

- Flash：存放程序代码。
- SRAM：存放变量、堆、栈等运行数据。
- 外设地址空间：GPIO、USART、SPI、TIM、CAN 等外设寄存器。
- 其他区域：中断向量表等。
